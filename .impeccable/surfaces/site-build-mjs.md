# Folio docs site

Scope: the GitHub Pages site generated from the repo markdown by site/build.mjs. Landing page (Persuade) at the root, documentation pages (Read) under it. Audience: UE5 developers evaluating or integrating Folio. Action: Hello world. Proof: README showcase videos and screenshots. Constraint: markdown stays the source and renders on github.com.

## Direction contract

THESIS: The landing is an arcade cabinet in attract mode; the docs are the operator manual kept in its coin door. Refuses the category default: centred headline over a feature-card grid, sidebar docs with a blue accent.

OWN-WORLD: Backlit marquee band in drenched side-art yellow with FOLIO in Bungee layered red over black shade; cabinet black body; three inks with one job each, red action, yellow trap, blue link; manual pages on cool white stock with Archivo text, Archivo Expanded heads, JetBrains Mono code set inside dark screen bezels; tables ruled like DIP-switch settings sheets; round control-panel buttons.

STORY: The visitor sees a game UI running, understands it is markup that stays sharp at any scale, believes it through the real showcase loop, and presses START into Hello world.

FIRST VIEWPORT: Marquee band across the top third, FOLIO at full width with the one-outline size ladder beside it; nav set into the marquee frame. Below, a bezel screen playing the showcase loop, and a control-panel strip under it whose red round START (Hello world) is the primary action, with blue Docs and yellow Studio buttons.
